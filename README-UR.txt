تذکیر 360 Prayer Display — ابتدائی اینڈرائیڈ پروجیکٹ

یہ ایک ابتدائی سورس پروجیکٹ ہے، ابھی تیار شدہ یا سائن شدہ APK نہیں۔

APK بنانے کا آسان راستہ:
1) GitHub پر اکاؤنٹ بنائیں یا سائن اِن کریں۔
2) نیا Public یا Private repository بنائیں، نام: Tazkeer360PrayerDisplay
3) اس ZIP کے اندر موجود تمام فائلیں repository میں اپ لوڈ کریں۔
4) Actions ٹیب کھولیں اور "Build Android APK" workflow چلائیں۔
5) مکمل ہونے کے بعد Artifacts میں Tazkeer360-PrayerDisplay-debug ڈاؤن لوڈ کریں۔
6) ZIP کھول کر app-debug.apk اپنے موبائل میں انسٹال کریں۔

چارجنگ ڈسپلے:
ایپ انسٹال ہونے کے بعد Settings > Display > Screen saver میں جائیں،
Tazkeer 360 Prayer Display منتخب کریں، اور When to start میں While charging منتخب کریں۔
فون کے ماڈل/Android ورژن کے مطابق مینو کے نام مختلف ہو سکتے ہیں۔

اہم حدود:
- یہ پہلا تکنیکی نمونہ ہے؛ GPS، متعدد حسابی طریقے، مکمل زبانیں، درست وقت کے زون،
  مستقل اپ ڈیٹ، اور لاک اسکرین ویجیٹ ابھی اگلے مراحل میں شامل ہوں گے۔
- لاک اسکرین پر مکمل متحرک ایپ دکھانا عام Android ایپس کے لیے محدود ہے۔
  اس نمونے میں چارجنگ اسکرین سیور فراہم کیا گیا ہے۔
- نمازوں کے اوقات AlAdhan سروس سے آتے ہیں؛ اپنے علاقے کی مسجد کے اوقات سے تصدیق کریں۔
- یہ Debug APK ہے، عوامی اشاعت کے لیے Release signing اور مزید آزمائش ضروری ہے۔
